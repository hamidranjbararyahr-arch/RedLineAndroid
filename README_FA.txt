پروژه اندرویدی بازی خط قرمز
=============================

این پروژه، نسخه موبایلی HTML بازی را داخل یک اپلیکیشن اندرویدی (WebView) اجرا می‌کند.
بازی برای اجرا به اینترنت نیاز ندارد.

روش ساخت APK:
1) Android Studio را روی کامپیوتر نصب کن.
2) فایل ZIP را از حالت فشرده خارج کن.
3) Android Studio را باز کن و گزینه Open را بزن.
4) پوشه RedLineAndroid را انتخاب کن.
5) صبر کن Gradle Sync کامل شود.
6) از منوی Build گزینه Build Bundle(s) / APK(s) و سپس Build APK(s) را انتخاب کن.
7) بعد از پایان ساخت، روی Locate بزن تا فایل app-debug.apk را پیدا کنی.
8) فایل APK را به گوشی منتقل و نصب کن. ممکن است اندروید اجازه نصب از این منبع را بخواهد؛ فقط در صورتی اجازه بده که فایل را خودت از همین پروژه ساخته‌ای.

نیازمندی‌ها:
- Android Studio نسخه‌ای سازگار با Android Gradle Plugin 8.7.3
- JDK 17
- Android SDK Platform 35

نکته:
این ZIP سورس پروژه آماده ساخت است، نه فایل APK نهایی. برای ساخت APK باید Gradle Sync و Build در Android Studio انجام شود.
