خط قرمز نسخه ۲.۰

پروژه اندروید WebView با بازی آفلاین فارسی، ۱۶۰ کارت در ۹ دسته، تم مشکی/قرمز/طلایی و لوگوی اختصاصی.
برای ساخت APK: محتویات این پوشه را در ریشه مخزن GitHub قرار دهید؛ Actions به صورت خودکار APK را می‌سازد.
نکته: برای به‌روزرسانی نسخه نصب‌شده، APK جدید باید نصب شود. چون امضای این بیلد با نسخه قبلی متفاوت است، ممکن است لازم باشد نسخه قبلی را حذف کنید؛ قبل از حذف، نام بازیکنان و امتیازها در نسخه قبلی را ثبت کنید.
